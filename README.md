# Голосовое расписание

Учебное приложение проверяет доступность времени. По московскому времени на завтра заданы два слота: 18:30 свободно, 19:00 занято. Для других дат сервер возвращает «нет данных». Операций записи в приложении нет.

## Запуск

Понадобятся Node.js 22+ и ключ Gemini API с доступом к бесплатной Live-модели. Перед запуском выполните `npm ci`.

1. Распакуйте архив и откройте терминал в папке `voice-schedule`.
2. Выполните `cp .env.example .env` и заполните `GEMINI_API_KEY` в файле `.env`.
3. Выполните `npm start` и откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).
4. Нажмите «Начать разговор», разрешите доступ к микрофону и дождитесь состояния «Слушает». Спросите «Можно завтра после шести?».

При необходимости задайте порт в `PORT`, а доступную модель Realtime — в `GEMINI_LIVE_MODEL`. Ключ используется сервером из переменной окружения и отсутствует в архиве. Ключ создаётся в Google AI Studio и хранится в .env.

## Архитектура

- **Realtime через WebSocket.** Браузер передаёт PCM-аудио 16 кГц серверу, сервер соединяется с Gemini Live официальным SDK `@google/genai`. Модель по умолчанию — `gemini-2.5-flash-native-audio-preview-12-2025`. Ответ PCM 24 кГц воспроизводится через Web Audio API по мере получения. Ключ остаётся на сервере.
- **Проверка расписания.** Gemini вызывает `check_availability`, сервер исполняет функцию и возвращает результат в ту же сессию. Инструкция требует использовать только результат проверки перед сообщением доступного времени.
- **Потоковая передача.** Браузер подключает удалённую звуковую дорожку сразу, по мере поступления аудио. Текст ответа дописывается по событиям транскрипции, текст вопроса появляется после распознавания.
- **Управление сессией.** При завершении браузер закрывает WebSocket, отсоединяет звук, останавливает микрофон и отменяет незавершённые запросы. Новый запуск очищает текст и открывает отдельную сессию. Перебивание и восстановление контекста в эту версию не входят.

## Четыре сценария для демонстрации

| Сценарий | Что должно произойти |
| --- | --- |
| «Можно завтра после шести?» | Помощник сообщает, что 18:30 свободно, а 19:00 занято. В интерфейсе видны вопрос, этап проверки и текст ответа. |
| «Что свободно послезавтра?» | Помощник сообщает, что на эту дату нет данных. |
| Ошибка расписания и повтор | Установите `DEMO_FAIL_FIRST_CHECK=1` в `.env`, перезапустите сервер и спросите про завтра. Первая проверка вернёт ошибку, интерфейс предложит задать вопрос снова. Дождитесь состояния «Слушает» и повторите вопрос в том же разговоре. Верните `DEMO_FAIL_FIRST_CHECK=0` для обычной работы. |
| Завершение во время ответа | Нажмите «Завершить», пока помощник говорит. Звук должен остановиться. Нажмите «Начать разговор». История очищается, старый ответ не возобновляется. |

`npm test` проверяет серверное расписание: доступные и занятые слоты, отсутствие данных и ошибку с повтором. Голосовые сценарии и завершение во время воспроизведения требуют отдельного живого прогона по таблице выше.

## Развёртывание на Render Free

Используйте Web Service с планом Free. В репозитории есть render.yaml для развёртывания через Blueprint. Укажите серверную переменную GEMINI_API_KEY в Render Dashboard. Значение ключа отсутствует в репозитории.

При ручной настройке задайте Build Command `npm ci`, Start Command `npm start`, регион Frankfurt и план Free. Render автоматически предоставляет HTTPS, публичный адрес и PORT. Приложение поддерживает WSS на публичном адресе.

Откройте опубликованный адрес, нажмите «Начать разговор», разрешите микрофон и дождитесь «Слушает». После простоя 15 минут бесплатный сервер засыпает, первый запуск может занять около минуты.

Для демонстрации ошибки установите DEMO_FAIL_FIRST_CHECK=1 и перезапустите сервис. Первая проверка расписания завершится учебной ошибкой. После демонстрации верните 0. Модель Gemini использует бесплатную квоту вашего проекта.
